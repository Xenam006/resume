# Глоссарий предметной области: «Семейный аккаунт»

| Термин | Определение |
|---|---|
| **Семейный аккаунт** | Объединение до 6 пользователей с общими адресами, способами оплаты и историей заказов, управляемое владельцем. |
| **Владелец** | Пользователь, создавший семейный аккаунт; управляет участниками, ролями, лимитами и общим кошельком. |
| **Участник** | Пользователь, приглашённый в семейный аккаунт. Бывает с ролью «взрослый» или «подросток». |
| **Роль** | Набор прав участника внутри аккаунта. «Взрослый» — полный доступ к заказам; «подросток» — заказы в рамках лимита/подтверждения. |
| **Общий кошелёк** | Общий баланс/способ оплаты семейного аккаунта, с которого оплачиваются заказы участников. |
| **Лимит трат** | Максимальная сумма, которую подросток может потратить за период без подтверждения владельца. |
| **Остаток лимита** | Разница между лимитом и уже потраченной за период суммой. |
| **Подтверждение заказа** | Согласие владельца на заказ подростка, превышающий остаток лимита. |
| **Согласие на обработку ПДн** | Юридическое согласие участника на обработку персональных данных в соответствии со 152-ФЗ, запрашиваемое при вступлении. |
| **Законный представитель** | Родитель/опекун, выполняющий юридически значимые действия за ребёнка до 14 лет. |
| **Токенизация** | Замена реальных платёжных реквизитов на токен, чтобы участники не видели номер карты. |
| **Идемпотентность операции** | Свойство, при котором повторный вызов операции оплаты не приводит к повторному списанию. |
| **Retention (удержание)** | Доля пользователей/аккаунтов, продолжающих активно пользоваться сервисом спустя период. |
| **JTBD (Job To Be Done)** | Реальная задача, которую пользователь «нанимает» продукт решить. |
