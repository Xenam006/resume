## Как читать это портфолио

Каждый кейс лежит в отдельной папке и начинается со своего `README.md`, где коротко описаны контекст, что сделано и какой получился результат. Диаграммы (BPMN, ER, процессы) нарисованы в двух форматах: **Mermaid** — отображается прямо на странице GitHub, и **BPMN 2.0 XML** — открывается в Camunda Modeler / Bizagi. SQL-скрипты самодостаточны: создают схему, наполняют её синтетическими данными и запускаются в PostgreSQL.

## Чем владею

**Работа с требованиями.** Выявление (интервью, воркшопы, анализ документов), документирование (BRD, функциональные и нефункциональные требования, user stories с критериями приёмки в формате Given/When/Then, use cases), приоритизация (MoSCoW, RICE), трассировка и управление изменениями, валидация по INVEST и SMART.

**Моделирование.** BPMN 2.0 (AS-IS / TO-BE, шлюзы, события, пулы и дорожки), UML (use case, activity, sequence), ER-моделирование данных, Customer Journey Map.

**Анализ бизнеса.** «5 почему», диаграмма Исикавы, дерево проблем, Gap-анализ, бизнес-кейс (ROI, срок окупаемости), unit-экономика (CAC, LTV, retention, churn), SWOT.

**Данные.** SQL (JOIN, GROUP BY, подзапросы, CTE, оконные функции, когортный анализ), Excel/Sheets на продвинутом уровне, BI (дашборды под конкретного читателя), базовая статистика.

**Техническая грамотность.** Клиент-серверная архитектура, REST API (чтение Swagger/OpenAPI, запросы в Postman), JSON, модели данных, SDLC, основы 152-ФЗ.

**Методологии.** Agile (Scrum, Kanban), Waterfall (где уместен), BABOK.
