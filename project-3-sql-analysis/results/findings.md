# Выводы по SQL-анализу продаж

> Данные синтетические и сгенерированы процедурно (`02_seed.sql`, `setseed(0.42)`). Цифры ниже — иллюстративные, они показывают **формат вывода и бизнес-интерпретацию**; точные значения воспроизводятся запуском скриптов на вашей PostgreSQL. Главное в кейсе — умение перевести бизнес-вопрос в корректный SQL и сделать из результата вывод.

---

## Вопрос 1–2. Где делается выручка?

**Что считали:** выручку и её долю по категориям (`Q1`, `Q2`).

**Как читать результат:** на вершине обычно 2–3 категории с высоким средним чеком (например, «Электроника», «Авто»), которые дают непропорционально большую долю выручки при меньшем числе заказов. Категории с частыми, но дешёвыми покупками («Книги», «Продукты») дают много заказов, но мало выручки.

**Вывод для бизнеса:** правило Парето почти всегда работает — ~20% категорий дают ~70–80% выручки. Это аргумент для приоритизации ассортимента, промо и логистики в пользу высокомаржинальных категорий, при этом «частотные» категории важны для удержания и трафика.

---

## Вопрос 3. Как меняется выручка во времени?

**Что считали:** помесячную выручку и прирост к прошлому месяцу (`Q3`, `LAG`).

**Как читать результат:** видно сезонность и помесячную динамику (столбцы `mom_change`, `mom_pct`). Отрицательные `mom_pct` — месяцы просадки, их стоит сопоставить с промо-календарём и запасами.

**Вывод для бизнеса:** динамика MoM — базовый индикатор здоровья; на неё опираются план продаж и закупки.

---

## Вопрос 4. Возвращаются ли клиенты?

**Что считали:** долю повторных покупателей (`Q4`).

**Как читать результат:** `repeat_rate_pct` показывает, какая доля клиентов сделала больше одного заказа. Низкий повторный процент — сигнал проблемы с удержанием, а не с привлечением.

**Вывод для бизнеса:** если повторные покупки низки, вложения в привлечение «утекают» — сначала нужно чинить retention (онбординг, подписки, программы лояльности).

---

## Вопрос 5. Как удерживаются когорты?

**Что считали:** когортное удержание по месяцу первого заказа (`Q5`).

**Как читать результат:** для каждой когорты видно, сколько клиентов активны через 1, 2, 3… месяца. Обычно кривая резко падает после `month_number = 0` и затем стабилизируется — «плато удержания».

**Вывод для бизнеса:** сравнение когорт показывает, улучшаются ли изменения в продукте. Если поздние когорты удерживаются лучше ранних — продукт развивается в правильную сторону.

---

## Вопрос 6. Какой отток?

**Что считали:** долю клиентов без заказов более 90 дней (`Q6`).

**Вывод для бизнеса:** `churn_rate_pct` — кандидаты на реактивационные кампании. Высокий отток при высоком среднем чеке — приоритет №1 для работы.

---

## Вопрос 7. Кого удерживать в первую очередь? (RFM)

**Что считали:** RFM-сегментацию через квинтили (`Q7`, `NTILE`).

**Как читать результат:** клиенты с `r_score=5, f_score=5, m_score=5` — «чемпионы» (недавние, частые, дорогие). `r_score=1, f_score=5` — «уходящие ценные», их важно вернуть.

**Вывод для бизнеса:** RFM превращает список клиентов в план действий: кого беречь, кого реактивировать, на ком не тратить бюджет.

---

## Вопрос 8. Средний чек и ARPU

**Что считали:** AOV и ARPU (`Q8`).

**Вывод для бизнеса:** базовые опорные метрики для unit-экономики; рост AOV (кросс-сейл, бандлы) — один из самых быстрых рычагов выручки.
