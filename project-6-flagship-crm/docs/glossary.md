# Глоссарий предметной области: CRM фитнес-сети

| Термин | Определение |
|---|---|
| **Клуб** | Отдельный фитнес-клуб сети со своим расписанием и залами. |
| **Клиент** | Физлицо, пользующееся услугами сети; имеет домашний клуб, но может ходить в любой. |
| **Тариф (тип абонемента)** | Шаблон абонемента: срок действия, лимит посещений, цена. |
| **Абонемент (membership)** | Проданный клиенту экземпляр тарифа с датами начала/окончания и остатком посещений. |
| **Статус абонемента** | `активен`, `истёк`, `заморожен`. Определяет, можно ли записываться и ходить. |
| **Заморозка** | Приостановка абонемента на период с переносом даты окончания. |
| **Остаток посещений** | Сколько посещений ещё доступно по абонементу (для лимитных тарифов). |
| **Групповое занятие (сессия)** | Конкретное занятие в расписании: клуб, тренер, время, вместимость. |
| **Вместимость (capacity)** | Максимальное число клиентов на занятии. |
| **Бронь (booking)** | Запись клиента на конкретное занятие. Статусы: `активна`, `отменена`, `посещено`, `неявка`. |
| **Лист ожидания** | Очередь клиентов на заполненное занятие; при освобождении места бронь подтверждается. |
| **Check-in** | Отметка прихода клиента в клуб/на занятие, списывающая посещение. |
| **Неявка (no-show)** | Клиент записался, но не пришёл и не отменил бронь. |
| **Посещение (visit)** | Факт прихода клиента, зафиксированный системой. |
| **Продление** | Покупка нового срока по действующему абонементу до/после его окончания. |
| **Оплата (payment)** | Финансовая операция по продаже/продлению абонемента. |
| **Загрузка зала** | Доля занятых мест на занятиях за период — метрика эффективности расписания. |
| **Конверсия в продление** | Доля клиентов, продливших абонемент после окончания. |
